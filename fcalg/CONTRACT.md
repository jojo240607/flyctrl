# fcalg 契约 —— 单一真值源

> 本文是重建后的唯一约定来源。**实现与本文冲突 ⇒ 实现错**；改约定必须先改本文。

## 0. 与仿真/plant 的边界（硬约束）

算法层每个模块的验收**只由解析合成输入驱动，不经过仿真器**；仿真器只在最后的集成验收出现。
理由：模块判定一旦依赖 sim 保真度，"算法错"与"仿真错"会重新纠缠 —— 那正是本次重建要摆脱的。

## 1. 单位

一律 SI。量纲**类型显式**（`Meters`/`Mps`/`Radians`/`Rps`/`Seconds`）。
**不做隐式数值转换** —— 混合量纲必须显式转换。

## 2. 坐标系与符号（唯一定义）

| 项 | 约定 |
|---|---|
| 世界系 | **NED**：x=北(前)、y=东(右)、z=下；右手 |
| 机体系 | **FRD**：x=前、y=右、z=下；右手 |
| 姿态 `q` | **机体 → 世界**，分量序 **w,x,y,z**，单位模 |
| 角速度 `ω` | **机体系** |
| 比力 `f_b` | **机体系**；静止水平时 = `(0,0,−g)`（指向天，因 z 向下） |
| 重力 | `GRAVITY_NED = (0,0,+g)` |
| 欧拉角 | **ZYX 内旋**：先 z(yaw) 再 y(pitch) 再 x(roll)；`rpy[0]=roll` |

**比力关系（L4 静止对齐必须反解）**：`f_b = R(q)ᵀ · (−GRAVITY_NED)`
⇒ 静止水平时 `f_b = (0,0,−g)`。本式是约定自洽的判据（见 `tests/l0_contract.rs`）。

## 3. 时间

样本带硬件戳且单调；`dt` 由相邻戳差（非名义周期）；`dt_ang`/`dt_vel` **双口径必须同时给出**；
`dt ≤ 0` 或超阈值 ⇒ 丢帧 + 计数，不得静默使用。

## 4. 有限性纪律（L1）—— 永不静默

每模块输入与输出都必须有限；出现 NaN/±Inf ⇒ **当场上报（按阶段计数）+ 拒绝继续**。
**不得**把 NaN 钳成某个"安全"地板值 —— 那会销毁证据并制造"看起来正常"的假象。

## 5. 模块契约模板

每个模块必须声明：输入（类型/量纲/帧/前置）、输出（类型/量纲/帧/后置）、失败模式（显式）、预算量级。

## 6. 验收准则（只允许这四类）

1. **有限差分裁判** —— 解析式 ↔ 数值导数
2. **不变量** —— 正交、对称、正定、保模、守恒
3. **极限/退化** —— `F=I`、`dt=0`、零残差、`H=`选择矩阵、零输入
4. **可解析合成输入** —— 已知运动 ⇒ 可手算真值

**禁止**：先跑一遍实现、把输出记下来当期望值。

## 7. 明确不继承

- 旧验收用例与阈值（已实测多条陈旧：`x_sensor_rate` 的 200~500 Hz 标定于快 14% 的时钟；
  `x_task_stall` 的 `q_total > 2400` 编码的是已删除的 1 kHz sensors 线程）；
- 旧诊断工具的硬编码地址/区间；
- "把非有限值钳成地板"这类静默兜底。

PX4 一手源码**仍可作参考读**，但**不作为验收阈值**。
